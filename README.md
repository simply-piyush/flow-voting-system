# 🗳️ Flow Voting System (Solidity + Remix)

A simple decentralized **Voting System smart contract** built and deployed on **Flow EVM Testnet** using **Solidity** and **Remix IDE**.

---

## 🚀 Overview

This project allows users to vote for their favorite proposals in a transparent, on-chain way.  
Each address can vote only once, and only the contract owner can end the voting session.

Built as part of the **Flow Build Station Workshop** and submitted to the **Forte Hacks Global Hackathon** via **HackQuest**.

---

## 🧱 Tech Stack

- **Solidity (0.8.20)**
- **Remix IDE**
- **MetaMask**
- **Flow EVM Testnet**
- **HackQuest Hackathon Platform**

---

## ⚙️ Setup & Deployment

### 1. Connect to Flow EVM Testnet
Add Flow EVM Testnet to MetaMask from Chainlist:  
🔗 [https://chainlist.org/chain/545](https://chainlist.org/chain/545)

### 2. Get Test Tokens
Claim free test tokens to cover gas fees:  
🔗 [https://faucet.flow.com/fund-account](https://faucet.flow.com/fund-account)

### 3. Deploy Using Remix
1. Go to [Remix IDE](https://remix.ethereum.org)
2. Create a new file named `VotingSystem.sol`
3. Paste the contract code
4. Compile with **Solidity 0.8.20**
